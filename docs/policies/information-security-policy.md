# 星澜科技信息安全与权限管理制度

## 1. 数据分级
- 员工档案、薪酬、绩效、候选人简历、客户合同属于敏感信息
- 内部制度、流程文档和运营报表属于内部信息
- 对外公开招聘信息、市场宣传材料属于公开信息

## 2. 账号与权限
- 新员工账号由信息技术支持部在入职前准备，默认按最小权限开通
- 涉及薪酬、绩效、合同和候选人简历的权限需经部门负责人或人力资源团队审批
- 员工离职、转岗、长期休假时，信息技术支持部需在一个工作日内完成权限调整

## 3. 设备与文件管理
- 公司发放的电脑、显示器和门禁卡均纳入资产台账管理
- 内部制度文档原则上仅允许在公司系统内访问，不得随意外传
- 未经批准，不得通过私人邮箱、私人网盘或外部 IM 工具发送敏感数据

## 4. 安全事件处理
- 发现账号异常登录、权限误配、设备遗失或疑似数据泄露时，应在 30 分钟内联系信息技术支持部
- 信息技术支持部收到事件后应先完成账号冻结、设备封锁或访问撤销，再组织排查
- 严重事件由人力资源团队、法务和业务负责人共同介入处理

## 5. 密码与认证
- 密码至少每 180 天更新一次
- 管理员、人力资源团队和财务岗位必须启用双因素认证
- 禁止共享账号、代他人登录或借用高权限账号处理日常事务

## 6. 助手回答建议
- 当员工提问“账号权限找谁开通”“保密文件能否外发”“设备丢失怎么办”时，优先引用本制度
