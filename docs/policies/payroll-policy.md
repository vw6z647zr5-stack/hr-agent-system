# 星澜科技薪酬与工资单制度

## 1. 薪酬结构
- 公司采用月薪制为主，薪酬结构可包含基本工资、住房补贴、交通补贴、绩效奖金系数、社保基数与税率等。
- 薪资配置由人力资源团队与授权管理者维护，敏感金额默认仅对有权限的角色开放。

## 2. 工资记录生成
- 工资记录生成时会综合当月出勤、已批准加班、绩效得分及有效薪资配置。
- 系统会自动计算应发、扣减和实发金额，并可同步生成工资单文件。

## 3. 工资单发布
- 工资单按月统一发布。
- 员工可见状态为真的工资单会在员工自助端显示并支持下载。
- 未发布或未开放给员工的工资单，员工端不可见。

## 4. 员工查询与下载
- 员工可在自助工作台的薪酬区域查看最近工资单。
- 员工服务智能助手可说明工资单查看入口，但不会越权展示未授权金额。

## 5. 保密要求
- 工资数据属于敏感信息，员工不得对外传播本人或他人薪酬细节。
- 管理者、人力资源团队、系统管理员在处理工资数据时应遵守最小知悉原则。
