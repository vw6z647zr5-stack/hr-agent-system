# 星澜科技员工手册（节选）

## 1. 适用范围
- 本手册适用于星澜科技全体正式员工、试用期员工与经审批纳入统一制度管理的实习人员。
- 所有员工在入职、任职、异动、请假、绩效、薪酬与信息安全方面，均需遵守本手册及配套专项制度。

## 2. 工作时间与办公方式
- 标准工作时间为周一至周五 `09:00-18:00`，午休 `12:00-13:00`。
- 公司实行总部现场办公与混合办公结合的模式。员工如需远程办公，应按部门规则提前报备直属主管。
- 法定节假日按照中国大陆国家法定安排执行。

## 3. 考勤要求
- 员工需通过公司统一系统完成上班、下班打卡。
- 迟到、早退、漏打卡与异常打卡会进入考勤异常队列，由员工补充说明，主管和人力资源团队按需复核。
- 连续出现考勤异常的员工，直属主管应在一周内完成沟通并确认原因。

## 4. 信息更新与员工责任
- 员工应保证联系方式、住址、紧急联系人、银行卡脱敏信息等资料准确。
- 员工资料发生变化时，应通过员工自助端提交资料变更申请，由人力资源团队审批通过后生效。
- 员工不得私自共享他人工资单、合同、身份证信息、客户资料与内部制度文档。

## 5. 保密与数据安全
- 员工须遵守最小权限原则访问系统数据。
- 未经批准，不得导出、传播或对外披露员工档案、薪酬、绩效、候选人简历和内部制度内容。
- 发现账号异常、权限误配、数据泄露风险时，应第一时间联系信息技术支持与人力资源部门。
