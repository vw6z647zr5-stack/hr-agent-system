# 星澜科技请假与休假制度

## 1. 请假申请原则
- 所有请假申请必须通过员工自助系统提交。
- 员工需填写假期类型、开始时间、结束时间、时长和请假原因。
- 默认审批链路为直属主管审批；出现异常、跨部门安排冲突或资料不完整时，由人力资源团队进一步复核。

## 2. 假期类型
- 年假：根据员工年度可用余额计算。
- 病假：员工需如实填写原因；连续病假可按公司要求补充证明材料。
- 婚假、产假、陪产假：按国家法规与公司制度执行。
- 事假：原则上优先提前申请，紧急情况可补提。

## 3. 审批与生效
- 状态为“待审批”时，表示申请已提交但尚未生效。
- 状态为“已通过”时，系统会同步至审批时间线，并纳入后续统计。
- 状态为“已驳回”时，员工应查看驳回原因并按需重新提交。

## 4. 年假余额查询
- 员工可在员工自助工作台查看年假、病假等可用余额。
- 员工服务智能助手也可基于系统实时数据返回当前余额。

## 5. 管理要求
- 主管在处理请假申请时，应兼顾业务安排与团队负荷。
- 人力资源团队可针对高频异常请假、冲突排班或资料不完整的申请进行二次核查。
