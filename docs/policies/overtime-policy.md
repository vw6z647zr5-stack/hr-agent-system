# 星澜科技加班与调休规则

## 1. 适用场景
- 加班适用于版本发布、线上故障处理、客户交付窗口、跨部门紧急支持等经主管确认的业务场景。
- 不鼓励无计划、低效率或无明确业务目标的常态化加班。

## 2. 申请要求
- 员工需在系统中填写加班日期、开始时间、结束时间、加班小时数和原因。
- 原则上应先申请后执行；紧急场景可先执行、后补录，但须在一个工作日内完成。

## 3. 审批要求
- 直属主管负责判断加班必要性与工时合理性。
- 已审批通过的加班记录会在薪酬模块生成工资记录时进入结算依据。
- 未通过审批的加班申请不会计入薪酬统计。

## 4. 风险控制
- 单次加班时长明显异常时，主管应确认工作内容与员工健康风险。
- 连续高强度加班的员工应由主管安排节奏调整，并在团队排期中体现风险缓冲。

## 5. 员工查询
- 员工可在自助端查看最近加班申请、审批状态及本月已核准工时。
- 员工服务智能助手可解释加班流程、状态含义及工资结算关系。
