# 星澜科技组织与服务目录

## 核心部门
- 人力资源部：招聘、组织发展、员工关系、制度运营
- 工程平台部：应用开发、数据平台、系统集成、稳定性建设
- 产品设计部：产品规划、需求分析、交互设计、可用性研究
- 客户成功部：客户交付、上线陪跑、续费运营、满意度管理
- 财务与行政部：薪酬复核、预算管理、合同归档、行政采购
- 信息技术支持部：账号权限、设备管理、网络与信息安全

- 工程负责人：张衡，负责核心系统研发与平台交付
- 产品负责人：周岚，负责产品规划与体验设计

## 常见服务入口
- 员工资料变更：员工自助端提交，人力资源团队审批后生效
- 请假与加班：员工自助端提交，直属经理审批
- 合同与工资单：员工在自助门户查看，人力资源团队和管理员可统一管理
- 招聘与面试：招聘工作台统一维护岗位、候选人和面试安排
- 设备与账号支持：提交 IT 支持工单或联系信息技术支持部

- 公司有哪些核心部门和负责人？
- 员工需要联系哪个部门处理账号或设备问题？
- 资料变更、请假、工资单分别走什么入口？
